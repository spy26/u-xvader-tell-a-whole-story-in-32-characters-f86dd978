**We Have Your WiFi. Send Pizza.** — 30 characters.

A ransom note for a Wi-Fi network, with a demand of pizza. The kidnapper, the
victim (you, reading your own network list), the hostage (your Wi-Fi) and the
demand are all in one line — a whole story in 30 characters.

## Run it

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when set), as UTF-8 with no trailing newline.
